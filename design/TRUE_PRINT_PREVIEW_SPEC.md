## 1. Single Source of Truth Principle

The Print Preview must never be an artist's mock-up or approximate decoration. It is generated by **the exact same physical rendering pipeline** that renders print jobs to the Windows Spooler and exports to PDF/PNG.

```
       [PageLayoutModel] (Millimeters, Margins, Offsets, DPI)
                          │
       ┌──────────────────┴──────────────────┐
       ▼                                     ▼
[Screen Preview Render]             [Windows Spooler Render]
SKBitmap @ 150/300 DPI              GDI+ / XPS @ 600 DPI
(Exact identical coordinate math)    (Exact identical coordinate math)
```

---

## 2. Driver-Reported Physical Capabilities

For the selected printer and media profile:
1. **Actual Paper Dimensions:** Query driver `PaperSize` or media definition.
2. **Hard Margins:** Query `PageImageableArea` / `HardMargins` from Windows print driver. Non-printable edge regions are shaded in cross-hatched red/gray.
3. **Card Placement & Trajectories:** Renders card silhouettes with millimeter markers.
4. **Hardware Offsets:** Shows fine-tuning calibration offsets ($\pm 0.1$ mm) with direction arrows (◀, ▶, ▲, ▼).

---

## 3. In-Preview Direct Editing

The operator can adjust the print layout directly on the preview sheet:
- Drag cards to reposition.
- Nudge X/Y offsets numerically or via directional buttons.
- Switch paper/media profiles (Epson L805 Tray, L8050 Tray, Canon Tray, A4 10-Card Dragon Sheet, 4x6" Sheet).
- Toggle Mirror Mode (for thermal lamination sheets).
- Real-time instant preview update upon any parameter modification.

---

## 4. Operator Approval Gate

- The print button is labeled **`START PRINTING`** and requires explicit approval.
- An informative pre-flight checklist verifies:
  - Valid printer selected and online.
  - Media tray loaded and clear of obstructions.
  - Front/back card assignments confirmed.
  - Zero-Citizen-PII compliance active.
- Printing spools directly to the Windows Spooler and logs the transaction fee to the local SQLite ledger.

---

## 5. Export Capabilities

- **Save Editable Layout:** Saves the current preview as a `.pvcproj` / JSON layout project.
- **Export to High-Resolution PDF:** Vector/raster composite PDF at 600 DPI matching physical paper dimensions.
- **Export to High-Resolution PNG:** Lossless 600 DPI raster image for verification or digital archiving.
